# Arquiteturas de Dados

Material gratuito do QG da Engenharia de Dados. Você recebeu porque comentou **ARQUITETURA**.

## Como usar este material

1. Abra o arquivo [arquiteturas-de-dados.pdf](arquiteturas-de-dados.pdf) → clique em **Download** se quiser guardar
2. Leia na ordem → cada slide é uma arquitetura com o desenho do fluxo
3. No fim → faça o exercício abaixo com um sistema que você conhece

## O que tem nos slides

→ O fluxo base do dado: origem, ingestão, armazenamento, transformação e consumo
→ Lambda: batch e tempo real em paralelo
→ Kappa: tudo como streaming
→ Medallion: bronze, silver e gold
→ Lakehouse: data lake com recursos de warehouse
→ Tabela comparando as 4 e como escolher

## Para praticar

Pense em um app que você usa (banco, delivery, streaming de vídeo) e responda:

1. Quais dados precisam estar disponíveis em segundos? Quais podem esperar um dia?
2. Qual das 4 arquiteturas você usaria? Por quê?
3. Desenhe o fluxo com setas: origem → ... → consumo
